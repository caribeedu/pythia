# Changelog

## v1.0.1

- A clearer description of what sets Pythia apart: syntheses and connections over atomic claims, delivered through hooks and MCP.

## v1.0.0

First stable release.

- Ingests Claude Code sessions, GitHub pull requests, Slack, Confluence and the incident.io catalog into a base of atomic claims with provenance and time.
- Resolves entities and conflicts with an LLM, with reversible merges and verdicts, and a periodic drift sweep.
- Delivers knowledge through a hook push and five MCP tools.
- A web interface (Evolution, Explore, Sources, Usage, Costs, Quality, Config), a cost ledger with a monthly cap, and golden questions with a plain-search baseline.
